## 🚀 Projeto em destaque

### 🤖 SmartFlow AI

Plataforma empresarial Full-Stack baseada em arquitetura de microsserviços, integrando:

- CRM
- ERP
- Financeiro
- Gerenciamento de usuários
- Controle de acesso por perfis
- Assistente empresarial com Inteligência Artificial

O sistema possui integração automática:

**CRM → ERP → Financeiro**

Uma oportunidade marcada como ganha no CRM gera automaticamente um pedido no ERP e, após sua confirmação, uma conta a receber no Financeiro.

### Tecnologias
